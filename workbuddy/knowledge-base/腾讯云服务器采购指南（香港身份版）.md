## 二、方案 A：国际站个人认证（推荐，香港身份证可直通）

### 关键信息

| 项目 | 内容 |
|---|---|
| **官网** | https://intl.cloud.tencent.com（腾讯云国际站，与大陆站完全隔离） |
| **支持证件** | 香港身份证 / 护照 / 驾照 / 工作许可证（注册地=中国香港即可） |
| **认证时效** | 个人认证 2–4 个工作日审核 |
| **支付方式** | 国际信用卡（Visa / MasterCard / AE）、PayPal |
| **结算货币** | 美元（USD） |
| **香港节点** | ✅ 免 ICP 备案，即买即用 |
| **深圳员工访问延迟** | 约 20–40ms，完全够用 |

### 详细操作步骤（按钮级）

**第 1 步：注册账号**
1. 打开 https://intl.cloud.tencent.com
2. 右上角点 **Sign Up（注册）**
3. 用**海外邮箱**注册（Gmail / Outlook 优先；QQ 邮箱偶尔收不到验证邮件）
4. 填**香港手机号**接收验证码（内地手机号收不到国际站验证码）
5. 邮箱收验证邮件 → 点激活链接
6. 注册时选地区：**中国香港**（⚠️ 注册地区一旦选定不可修改，务必选香港）

**第 2 步：实名认证（不认证无法购买）**
1. 登录后进入控制台，右上角头像 → **Account Center（账号中心）**
2. 找到 **Verification / 实名认证** → 点提交认证
3. 选择 **Individual Account（个人认证）**
4. 上传证件：选「身份证/护照」，上传**香港身份证**清晰照片（JPG/PNG/PDF，≤10MB）
5. 填写：全名（与证件一致）、地址、证件号码
6. 提交后等待审核，**2–4 个工作日**出结果（站内信+邮件通知）

**第 3 步：绑定支付方式**
1. 控制台 → **Account Center → Payment Method → Add Payment Method**
2. 选择**国际信用卡**（Visa/MasterCard/AE，推荐）或 PayPal
3. 绑卡会**预授权 1 美元**验证（随后原路退回）
4. ⚠️ 注意：内地储蓄卡、人民币信用卡**无法扣款**；没有国际卡可找正规代理商代充

**第 4 步：购买服务器**
1. 顶部菜单 **Products → Compute**，二选一：
   - **Lighthouse（轻量应用服务器）**：新手首选，一键配置，性价比高 → 推荐
   - **CVM（标准云服务器）**：更灵活，适合以后要折腾的
2. 点 **Create Instance / 立即选购**
3. 关键配置：
   - **Region（地域）**：选 **Hong Kong（香港）**——离深圳近、免备案
   - **Instance（实例规格）**：员工共享办公工具建议 **2核4G** 起步（预算够上 4核8G）
   - **Image（镜像）**：Linux 选 Ubuntu 22.04 / CentOS；不想敲命令选**宝塔面板（BT Panel）镜像**
   - **System Disk（系统盘）**：默认 50GB SSD 即可
   - **Public IP（公网 IP）**：勾选分配
   - **登录方式**：推荐 SSH 密钥（生成 .pem 文件保存）；嫌麻烦选密码登录
4. 确认配置 → 勾选协议 → **立即购买**
5. 用绑定的国际信用卡 / PayPal 支付 → 服务器 **1–5 分钟**自动创建

**第 5 步：员工共享配置**
1. 控制台查看实例公网 IP + 登录信息
2. Mac 终端 SSH 连接：
   ```bash
   ssh -i 你的密钥.pem ubuntu@公网IP
   ```
3. 安装宝塔面板（如果用普通镜像）：
   ```bash
   # Ubuntu
   wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh
   ```
4. 员工访问：浏览器打开 `http://公网IP:8888`（宝塔面板地址），分配面板账号给员工
5. 安全加固：在安全组/防火墙开放必要端口（22/80/443/8888），限制访问 IP 范围

## 三、方案 B：中国站企业认证（法人香港身份也可以）

### 关键信息

| 项目 | 内容 |
|---|---|
| **官网** | https://cloud.tencent.com（腾讯云中国站） |
| **企业认证方式** | ⚠️ 法人香港身份**不能**走「法人微信扫码/人脸识别」（明确不支持港/澳/台法人），改走**对公账户打款认证**或**微信公众号认证** |
| **对公打款认证** | 用公司对公账户向腾讯云指定账户汇一笔 <1 元的随机金额 → 验证通过即认证成功 |
| **认证后** | 账号归属公司，后续员工共享、开票都规范 |
| **大陆节点** | 需 **ICP 备案**（以公司名义），备案需法人配合，香港身份可能需额外材料 |

### 详细操作步骤（按钮级）

**第 1 步：注册账号**
1. 打开 https://cloud.tencent.com → 免费注册（手机号 / 微信 / QQ 均可）
2. 登录后进入实名认证页：控制台 → 右上角头像 → **账号信息 → 认证状态 → 提交认证**

**第 2 步：企业认证（选对公打款方式）**
1. 选 **企业认证** → 开始企业认证
2. 填写企业信息：上传**营业执照**（深圳市职工国际旅行社有限公司），系统自动识别企业名称、统一社会信用代码
3. 填行业、通讯地址、企业联系人信息
4. **认证方式选择：对公账户打款认证**（⚠️ 不要选「法人微信扫码认证」，那不支持香港法人）
5. 系统生成一个**指定金额（<1 元）**的汇款信息（收款户名、账号、金额）
6. 用公司**对公账户**（网银/手机银行）汇款该指定金额
7. 汇款到账后系统自动校验 → **企业认证成功**

> 替代方案：如果公司有**已认证的微信公众号**，也可以走「微信公众号认证」路径，免打款。

**第 3 步：购买服务器（大陆节点）**
1. 顶部菜单 → **云服务器 CVM** 或 **轻量应用服务器 Lighthouse**
2. 地域选 **广州**（离深圳员工最近）
3. 配置参考：2核4G / 4核8G，50GB SSD，带宽 3–5M
4. 计费：新用户有优惠（如 4核4G 低至 38 元/年起，2核4G 约 484 元/年）

**第 4 步：ICP 备案（大陆节点必须）**
1. 购买后 30 天内需完成 ICP 备案，否则服务器会被暂停
2. 控制台 → **ICP 备案** → 以公司名义提交
3. 需要材料：营业执照、法人证件、网站负责人证件等
4. ⚠️ 法人是香港身份：备案系统对港澳台证件支持有限，**建议先联系腾讯云备案客服（400-910-0100）确认香港身份法人的备案材料清单**，避免卡壳

## 六、常见问题（FAQ）

### Q1：我没有国际信用卡怎么办？
**A**：方案 A 需要国际信用卡或 PayPal。若都没有，可：① 办一张香港/内地银行的 Visa/Master 双币信用卡；② 找腾讯云**授权代理商代充**（充值后自己操作购买）；③ 改走方案 B 用公司对公账户打款认证+人民币支付。

### Q2：香港身份证在大陆站做个人认证行不行？
**A**：可以，但大陆站个人认证要求使用**港澳居民来往内地通行证（回乡证）**，不是香港身份证本身。且个人账号不能承载公司业务，所以对 KK 的场景建议方案 A 或方案 B 企业认证。

### Q3：法人是香港身份，公司还能在中国站企业认证吗？
**A**：**能**。官方明确「企业是国内的，法人是外国人可以认证」，但**不能**走法人微信扫码/人脸识别路径，要用**对公账户打款认证**或**微信公众号认证**。

### Q4：香港节点服务器需要备案吗？
**A**：**不需要**。境外节点（含香港）免 ICP 备案，即买即用。这也是方案 A 的最大优势。

### Q5：深圳员工访问香港节点快吗？
**A**：快。香港—深圳专线延迟约 20–40ms，日常办公完全无感。比访问大陆节点（广州约 10–20ms）差距很小。

### Q6：买了服务器怎么给员工用？
**A**：推荐装**宝塔面板**（可视化，员工浏览器操作），或用 CAM（腾讯云访问管理）创建子账号分配给员工。轻量应用 Lighthouse 还支持微信小程序管理。

### Q7：方案 A 国际站是美元结算，贵不贵？
**A**：国际站价格以美元计，香港节点 2核4G 轻量服务器约 $5–8/月（合 ¥40–60/月），与大陆站促销价差距不大，且省了备案的麻烦。大陆站促销（¥199/年）更便宜但要备案。

### Q8：注册地区选错了能改吗？
**A**：**不能**。账号注册地区一旦选定不可修改，且必须与实名认证证件一致。所以方案 A 注册时务必选「中国香港」。
