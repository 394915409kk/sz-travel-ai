## 第一部分：B 路径 —— 会话存档 + 一维助手 SCRM

### 核心价值（为什么值得花这个钱）

AI 能读到客户私聊全文后，自动干四件事：
1. **AI 自动打标签**：客户说"太贵了"自动标 C 冷、"下个月想走"自动标 H 热——客户跟进表的意向等级从人工判断变成 AI 自动识别
2. **AI 话术推荐**：客服屏幕边实时弹出应答话术（对接我们的 54 条话术库），新人秒变销冠
3. **超时未回提醒**：客户消息超时未回自动告警（替代现在"哨兵扫表"的人工登记模式，变成真实消息级监控）
4. **负面情绪预警**：客户不满时立刻提醒介入，防差评防飞单

### 开通步骤（KK 操作，超管，共 3 步）

**第 1 步：企微后台启用「数据与智能专区」的会话存档**（约 10 分钟 + 审核 1-3 个工作日）

1. 电脑登录企业微信管理后台（work.weixin.qq.com）
2. 左侧菜单「管理工具」→「数据与智能专区」
3. 找到「企业会话内容」→ 点「启用」
4. 下载《企业微信会话内容存档开通确认函》模板 → 填写并**加盖企业公章** → 上传（支持 pdf/png/jpg，5M 以内）
5. 勾选同意《腾讯企业微信会话内容存档服务协议》→ 提交
6. 等待官方审核（一般 1-3 个工作日，通过后企微内会收到「企业数据存档」会话通知）

> ⚠️ 注意走「数据与智能专区」入口（300 元/人/年），**不要**走「管理工具→会话内容存档」的原生接口入口（900 元/人/年且需开发才能用）。专区版就是给 SaaS 应用对接用的。
>
> 📌 确认函不会填可联系一维助手客服协助（第 2 步添加应用后可找到客服入口）。

**第 2 步：企微工作台添加「一维助手 SCRM」应用**（约 3 分钟）

方式一（推荐）：企业微信 App → 工作台 → 搜索框输入「一维助手」→ 点「添加」
方式二：企微 PC 端管理后台 → 应用管理 → 第三方应用 → 添加应用 → 搜索「一维助手 SCRM」

**第 3 步：完成数据授权**（约 5 分钟）

1. 企微管理后台 → 应用管理 → 第三方应用 → 一维助手 SCRM → 授权信息
2. 「数据与智能专区权限」处点「去授权」→ 勾选会话内容、知识集相关权限 → 一键授权
3. 进入一维助手后台（work.yiweizhushou.com，用企微扫码登录）→ 配置存档员工范围（先只勾客服/销售岗，KK 和财务不用存档）

**试用期验证清单**（15-30 天免费试用期内逐项验证，全过再付款）：

| 验证项 | 标准 |
|---|---|
| 会话查看 | 能看到客服与客户的私聊记录，撤回消息也在 |
| AI 自动打标签 | 客户聊到意向后标签自动更新，准确率目测 >80% |
| AI 话术推荐 | 弹出的推荐话术与场景匹配，客服愿意用 |
| 超时提醒 | 设置 30 分钟未回复告警，实际触达及时 |
| 负面情绪监控 | 模拟客户抱怨，能触发预警 |

### 员工告知（合规必做，勿省略）

开通后企微会自动向存档范围内员工发送合规告知（员工无法关闭），聊天窗口顶部会显示"聊天内容将被企业存档"提示条，客户也可见。**这是法定合规要求，所有正规企业都这样**。建议 KK 在内部群发一句告知话术：

> 「公司开通会话存档用于服务质量管理和客诉追溯，正常工作沟通不受任何影响，规范服务即可。」

## 第二部分：C 路径 —— 微信客服（全自动 AI 入口）

### 分两阶段走（第一阶段零开发零成本）

**第一阶段：原生微信客服 + 智能回复**（本周可上线，无需任何开发）

开通步骤（KK 操作，超管，约 20 分钟）：

1. 电脑登录企业微信管理后台（work.weixin.qq.com）
2. 左侧「应用管理」→「应用」→ 找到「微信客服」→ 点开启
3. 「客服账号」处点「创建账号」：
   - 名称：职旅客服
   - 接待人员：贝宝玉 + 客服岗（人工兜底）
   - 接待规则：智能回复优先，未命中转人工
   - 超时结束聊天：可设 30 分钟
4. 「服务工具」→「智能回复」→ 按《AI 客服知识库底稿》配置关键词规则：
   - 每个场景建 1 组规则（签证咨询/航线航班/价格报价/酒店住宿/行程定制/逼单促销/售后关怀）
   - 触发词取问题示例中的关键词（如"签证""免签""ETA"→ 命中回塞班免签话术）
   - 高频 Top 20 条先配，长尾逐步补
5. 「接入场景」→「在微信内其他场景接入」→ 复制客服链接，配置到：
   - 公众号菜单（自定义菜单加"咨询客服"按钮）
   - 视频号主页（管理后台「微信客服应用-在视频号中接入」选择已绑定视频号）
   - 官网/落地页（微信外网页接入）

**第二阶段：API + 大模型全自动对话**（第一阶段跑出量后再上）

- 管理后台「微信客服应用 → API」→ 配置自建应用 → 开启「通过 API 管理微信客服账号」
- 所有消息回调给自建应用，由 AI（灌入 54 条话术 + 8 份知识库）直接自动回复，复杂问题转人工
- **前置条件**：需要一个 7×24 运行的接收回调服务（云函数/云托管，费用极低）+ 开发对接。**建议等第一阶段验证日均咨询量 >20 条再启动**，避免为低量上重炮

### C 路径效果预期

| 指标 | 第一阶段（智能回复） | 第二阶段（AI 对话） |
|---|---|---|
| 响应速度 | 关键词命中秒回 | 全语义秒回 7×24 |
| 覆盖率 | Top20 高频问题 | 全量知识库 |
| 人工介入 | 未命中转人工 | 仅复杂问题转人工 |
| 深夜/节假日 | 智能回复在岗 | AI 全自动在岗 |

## 风险与边界（如实告知）

1. **B 的会话存档开通前的聊天记录无法回溯**，只存开通后的——所以越早开通越好
2. **存档提示条**：员工和客户都会看到"聊天内容将被企业存档"提示——合规要求，无法隐藏，需提前告知团队
3. **C 第一阶段是关键词匹配**，不是真 AI 理解——命中率取决于触发词配置质量，长尾问题会转人工
4. **AI 大模型全自动对接（C 二阶段）需要开发资源**，现阶段不承诺时间表，等量起来再上
5. 一维助手 3 席位起购（约 900-1500 元/年），试用期内可随时放弃不花钱
