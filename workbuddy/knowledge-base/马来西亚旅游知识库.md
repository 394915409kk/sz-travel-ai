### 1.1 宗教文化禁忌速查

| 禁忌事项 | 说明 |
|---|---|
| 猪肉与酒精 | 马来穆斯林不食猪肉、不饮酒；点餐请确认清真（Halal）标识 |
| 清真寺着装 | 进入清真寺须脱鞋，女性须遮盖头发（门口免费借用长袍头巾），男女均需穿长裤/长裙遮住膝盖以上 |
| 斋月（Ramadan） | 穆斯林斋月期间日出至日落禁食，餐厅白天多不营业；游客可正常饮食，但请勿在穆斯林面前吃喝 |
| 右手原则 | 马来族习惯用右手进食与递物，避免用左手 |
| 头部忌讳 | 不要随意触摸他人头部（尤其儿童） |
| 拍照礼仪 | 拍摄清真寺、宗教场所及当地居民前先征得同意 |
| 衣着规范 | 进入政府部门、宗教场所需衣着得体；沙滩外避免过分暴露 |

## 二、签证与入境政策

> 数据来源：中国驻马来西亚大使馆公告 + 马来西亚移民局官网（2026-08-21 复核）

### 2.1 签证政策（重大利好：中马互免签证）

**《中华人民共和国政府和马来西亚政府关于互免持公务普通护照和普通护照人员签证的协定》已于 2025 年 7 月 17 日正式生效。**

| 项目 | 内容 |
|---|---|
| **适用对象** | 持有效中国公务普通护照、普通护照的中国公民 |
| **免签事由** | 休闲旅游、探亲访友、商务活动、交流访问、私人事务、医疗、国际运输（机组人员）等 |
| **单次停留** | 不超过 30 天（自入境当日起算） |
| **累计限制** | 每 180 天内累计停留不超过 90 天 |
| **超期情形** | 拟停留超 30 天或定居/工作/学习/新闻报道等，须提前申请相应签证（在线系统 https://malaysiavisa.imi.gov.my） |
| **豁免范围** | 入境、出境、过境均免签，马来西亚驻华使馆不再办理过境签证 |

### 2.2 入境必备材料（MDAC 电子入境卡 + 证件）

> ⚠️ **重要：所有免签入境的中国公民，必须在抵马前 3 天内在线填报马来西亚数字入境卡（MDAC），建议打印纸质确认信。**

| 材料 | 要求 |
|---|---|
| **护照** | 有效期至少 6 个月以上，无破损，预留空白页 |
| **MDAC 电子入境卡** | 抵马前 3 天内填报（https://imigresen-online.imi.gov.my/mdac/main），免费，填完保存/打印确认信 |
| **往返机票** | 已付款确认的往返机票，返程日期须在免签停留期内 |
| **酒店订单** | 已付款的、与停留天数相符的酒店订单或住宿证明 |
| **资金证明** | 1000 美元以上（或等值货币）资金证明，含现金、支票、银行卡、电子钱包等 |
| **问询准备** | 用英文或马来文应答移民官员关于行程的问询（可请同行人员协助） |

### 2.3 东马特别提醒（沙巴/砂拉越）

- 入境东马沙巴州、砂拉越州时，**须在机场移民局柜台加盖入境章**。
- 如发现漏盖，请及时联系移民官员补盖，避免离境时受阻。
- 东马与西马之间的旅行同样要经过移民检查，随身携带护照原件。

### 2.4 eNTRI / 电子签说明（备查）

> 自互免签证生效后，普通旅游行程已**无需**申请 eNTRI 或电子签。以下供特殊情况（如停留超 30 天、非免签事由）参考：

| 项目 | 说明 |
|---|---|
| **eNTRI** | 原面向中国公民的免签登记（单次 15 天），互免协定生效后旅游免签已覆盖，eNTRI 仅作为历史通道保留 |
| **eVISA 电子签证** | 通过马来西亚移民局在线系统（https://malaysiavisa.imi.gov.my）申请，适用于超过 30 天或工作/学习等事由 |
| **签证费用** | 旅游类在线申签官方费用约 220 马币起（以官网为准） |
| **办理材料** | 白底照片、护照首页扫描、酒店订单、往返机票、个人信息表 |

## 三、主要目的地详细说明

### 3.1 吉隆坡（Kuala Lumpur）—— 马来西亚首都·城市名片

马来西亚政治经济中心，现代摩天楼与多元文化街巷交织，是绝大多数中国游客的第一站。

| 景点 | 特色 | 门票/时间 |
|---|---|---|
| **国油双峰塔（Petronas Twin Towers）** | 世界最高双子塔（452m），41/42 层天桥、86 层观景台俯瞰全城；每天限量放票，需提前在线预订 | 非马国籍成人约 RM 80（约 ¥130–230），9:00–22:30 |
| **独立广场（Merdeka Square）** | 1957 年马来西亚独立宣言地，英殖民建筑群 + 百米旗杆，历史感强烈 | 免费，全天 |
| **国家清真寺（National Mosque）** | 现代伊斯兰建筑，层叠伞状屋顶，可容纳 1.5 万人礼拜；入内需穿长袍（免费提供） | 免费，游客开放时段限时 |
| **武吉免登（Bukit Bintang）** | 吉隆坡核心商圈，Pavilion 商场 + 星光大道，购物餐饮一站式 | 免费 |
| **茨厂街（Petaling Street）** | 吉隆坡唐人街，夜市小吃与摊位林立，海南鸡饭、肉骨茶、龙眼冰必试 | 免费，傍晚至深夜最热闹 |
| **黑风洞（Batu Caves）** | 印度教圣地，272 级彩虹阶梯通往石灰岩洞穴神庙，门口 42.7m 战神金像 | 免费，7:00–21:00 |
| **亚罗街（Jalan Alor）** | 露天美食街，沙嗲烤肉、烤鱼、海鲜大排档，每晚烟火气拉满 | 免费，傍晚开市 |

### 3.2 沙巴（Sabah）—— 东马婆罗洲·潜水天堂

位于婆罗洲北部，拥有东南亚最高峰神山（4,095m）、世界级潜水点与「世界三大最美日落」。

| 区域 | 亮点 | 说明 |
|---|---|---|
| **亚庇（Kota Kinabalu）** | 丹绒亚路海滩日落（全球三大日落之一）、加雅街周日市场、环滩岛/美人鱼岛跳岛、神山国家公园 | 市区即海滨城市，度假+城市两相宜 |
| **仙本那（Semporna）** | 「玻璃海」跳岛胜地，敦沙卡兰海洋公园、军舰岛、马达京、汀巴汀巴；巴瑶族海上村落 | 需从亚庇转机至斗湖，再车程 1.5h |
| **卡帕莱（Kapalai）** | 建在珊瑚礁上的水上屋度假村，推门即浮潜，被称「马尔代夫平替」 | 度假村一体式，含三餐潜水，建议提前 1–2 个月预订 |
| **马达京（Mataking）** | 一岛一酒店，沙洲相连大小马达京，浮潜绝佳，海龟/小丑鱼常见 | 高端度假村，适合蜜月 |
| **诗巴丹（Sipadan）** | 世界顶级潜水圣地，500m 深的海底断崖+海龟墙+杰克风暴，每日限 120 人登岛 | 需持 AOW 潜水证，名额紧张，至少提前 3 个月预约 |
| **神山（Mt. Kinabalu）** | 东南亚最高峰，两日一夜登顶看日出云海，需提前数月抢名额 | 全程向导+许可 |

> **计调提示**：沙巴行程通常为 5–6 天；仙本那潜水线需额外安排亚庇–斗湖国内航班。诗巴丹名额稀缺，报价时务必标注「名额待确认」。

### 3.3 兰卡威（Langkawi）—— 免税海岛·安达曼海明珠

马来西亚唯一免税岛，巧克力、酒类、化妆品价格低于本岛，适合购物+海岛度假组合。

| 景点 | 特色 | 门票/时间 |
|---|---|---|
| **天空之桥（Sky Bridge）** | 高悬 660m 的弧形悬索桥，俯瞰安达曼海群岛全景，需乘缆车上山 | 缆车往返约 RM 60–85 |
| **东方村缆车（Oriental Village）** | 上天空之桥必经，途经 3 站含 360° 观景台 | 同上 |
| **跳岛游（Island Hopping）** | 孕妇岛/湿米岛/狮子岛，红树林巡游+喂鹰，半日船程 | 约 RM 50–80/人 |
| **红树林生态游（Kilim Geoforest）** | 乘船穿越红树林河道，看鹰群、蝙蝠洞、鳄鱼洞，地质公园风光 | 约 RM 60–100 |
| **珍南海滩（Pantai Cenang）** | 兰卡威最热闹海滩，水上项目+酒吧街+免税店 | 免费 |
| **天空之桥夜景/落日巡航** | 帆船出海看日落 | 约 RM 100–200 |

### 3.4 马六甲（Melaka）—— 世界文化遗产古城

2008 年与槟城同列 UNESCO 世界文化遗产，殖民建筑+娘惹文化+马六甲海峡日落，距吉隆坡约 2 小时车程，适合一日或两日游。

| 景点 | 特色 |
|---|---|
| **荷兰红屋（Stadthuys）** | 东南亚最古老的荷兰建筑群，红色外墙是马六甲标志 |
| **鸡场街（Jonker Street）** | 华人老街，周末夜市人气爆棚，娘惹菜、鸡饭粒、椰子冰、榴莲煎蕊必试 |
| **马六甲海峡落日** | 圣保罗教堂山或游船出海看落日 |
| **圣保罗教堂遗址** | 16 世纪葡萄牙遗迹，山顶视野开阔 |
| **马六甲河游船** | 夜游两岸彩色壁画与殖民建筑 |

### 3.5 槟城（Penang）—— 美食之都·文艺胜地

马来西亚美食之都，乔治市入选世界文化遗产，街头壁画+骑楼+古早味美食，是文青与吃货必打卡地。

| 景点 | 特色 |
|---|---|
| **乔治市壁画（George Town Street Art）** | 著名立陶宛艺术家 Ernest Zacharevic 互动壁画散落街巷，租单车/步行打卡 |
| **极乐寺（Kek Lok Si）** | 东南亚最大佛教寺庙之一，万佛塔+巨型观音像，春节灯会闻名 |
| **升旗山（Penang Hill）** | 缆车登顶俯瞰乔治市与海峡，日出/夜景皆佳 |
| **姓氏桥（Clan Jetties）** | 华人水上村落，海景+历史故事 |
| **美食之都** | 炒粿条、福建虾面、亚参叻沙、煎蕊、海南鸡饭、娘惹糕——街头随便一家都好吃 |

### 3.6 云顶高原（Genting Highlands）—— 高原娱乐城

距吉隆坡约 1 小时车程的高原避暑地，缆车穿越雨林云海，拥有东南亚知名赌场与主题乐园。

| 项目 | 说明 |
|---|---|
| **云天缆车（Awana SkyWay）** | 马来西亚最长缆车，玻璃底车厢俯瞰雨林云海 |
| **云顶天城世界主题乐园（Genting SkyWorlds）** | 室内外主题乐园，过山车/高空项目，成人 1 日票约 ¥230–250 |
| **赌场（Casino）** | 云顶赌场为马来西亚合法赌场，**年满 21 岁**方可入内，须着正装（长裤+有领上衣），着装不符可现场租借 |
| **购物与美食** | 云天大道（SkyAvenue）商场、奥特莱斯、各国美食 |
| **住宿** | 第一世界酒店（经济）、云顶名胜世界多家五星酒店 |

> **客服注意**：赌场严禁向未成年人及未满 21 岁人士介绍/协助入内，报价中勿将赌场作为主推卖点，仅作客观介绍。

## 四、交通指南

### 4.1 中国—马来西亚直飞航线

吉隆坡是东南亚航空枢纽，中国主要城市均有直飞；东马（亚庇）亦有直飞。

| 出发城市 | 主要航司 | 参考时长 | 参考票价（经济舱单程） |
|---|---|---|---|
| 广州 | 南航、亚航、马航、春秋、九元 | 约 4 小时 | ¥600–1,500 |
| 深圳 | 南航、深航、亚航、马航、国航 | 约 4 小时 | ¥600–1,400 |
| 上海 | 东航、南航、春秋、亚航长途、吉祥、上航 | 约 5–6 小时 | ¥700–1,700 |
| 北京 | 马航、亚航长途、南航 | 约 6 小时 | ¥900–1,800 |
| 成都/重庆/昆明/杭州/武汉等 | 南航、亚航、马航 | 4–6 小时 | ¥600–1,600 |
| **深圳/广州/上海/北京直飞亚庇** | 南航、亚航、马航 | 约 3–4 小时 | ¥800–1,800 |

> **票务提示**：亚航（AirAsia）为廉价航空，行李额需单独购买；旺季（12–2 月、暑期、春节）票价上浮明显，建议提前 1–2 个月出票。

### 4.2 国内交通

| 方式 | 说明 | 参考 |
|---|---|---|
| **国内航班** | 亚航/马航/马印航空等，吉隆坡↔亚庇约 2.5 小时，吉隆坡↔仙本那（斗湖）约 3 小时 | 单程 ¥300–800 |
| **城际大巴** | 吉隆坡↔马六甲约 2 小时，吉隆坡↔槟城约 4–5 小时，经济实惠 | ¥30–80 |

| **出租车/Grab** | 吉隆坡市内 Grab 叫车便捷，比出租车便宜，明码标价 | 起步约 RM 3–5 |

### 4.3 租车自驾

| 项目 | 说明 |
|---|---|
| **驾驶方向** | **右舵左行**（靠左行驶），过马路「先看右、再看左」 |
| **驾照要求** | ⚠️ 中国驾照（含翻译件）**不可直接使用**，须持马来西亚合法驾照或国际驾照；严禁无证驾驶 |
| **租车费用** | 吉隆坡约 RM 120–250/天，兰卡威约 RM 80–150/天 |
| **注意事项** | 随身携带护照备查、全程系安全带、不超速不酒驾不疲劳驾驶 |

### 4.4 Grab 打车要点

- 马来西亚最常用网约车平台，支持中文界面+现金/信用卡/电子钱包支付。

## 十、客户 FAQ（标准应答）

### Q1：去马来西亚旅游需要签证吗？
**A**：不需要。自 2025 年 7 月 17 日中马互免签证协定生效后，持有效期 6 个月以上的中国普通护照，以旅游等事由可**免签入境停留不超过 30 天**（每 180 天累计不超过 90 天）。

### Q2：入境前需要办理什么手续？
**A**：抵马前 3 天内在线填报**马来西亚数字入境卡（MDAC）**（免费），并打印确认信；同时备好往返机票、酒店订单和资金证明（1000 美元以上或等值货币）。

### Q3：从国内哪些城市可以直飞马来西亚？
**A**：广州、深圳、上海、北京、成都、昆明、杭州、武汉、重庆等城市均有直飞吉隆坡航班，航程约 4–6 小时；深圳/广州/上海/北京也有直飞沙巴亚庇的航班。

### Q4：马来西亚最佳旅游季节是什么时候？
**A**：全年皆宜。西马西海岸 11 月–次年 3 月为旱季最佳；沙巴 3–10 月旱季；东海岸岛屿 3–10 月开放。

### Q5：去仙本那潜水有什么要求？
**A**：浮潜无门槛；深潜需 PADI 证书。诗巴丹为顶级潜水点，每日限 120 人，需提前 3 个月以上预约名额。

### Q6：在马来西亚能刷支付宝/微信吗？
**A**：吉隆坡、槟城等大城市商场和连锁店普遍支持支付宝/微信/Grab Pay；小摊贩和夜市仍以现金为主，建议备少量马币。

### Q7：中国驾照能在马来西亚租车吗？
**A**：不能直接使用。马来西亚为右舵左行，须持当地合法驾照或国际驾照；中国驾照（含翻译件）不可租车驾驶。

### Q8：带孩子去马来西亚推荐去哪？
**A**：推荐吉隆坡（双峰塔/水族馆/云顶乐园）+ 兰卡威或亚庇的海岛度假村，亲子设施完善，飞行时间短，语言沟通无障碍。

### Q9：去清真寺参观需要注意什么？
**A**：需脱鞋入内，女性遮盖头发，男女均须穿长裤/长裙遮住膝盖以上；多数清真寺门口免费提供长袍，参观时保持安静，勿打扰礼拜。

### Q10：在马来西亚购物可以退税吗？
**A**：可以。在标有「游客退税」的商家单次消费达规定金额，保留购物小票，离境时在机场办理退税；兰卡威为免税岛，酒类、巧克力、化妆品直接免税。
