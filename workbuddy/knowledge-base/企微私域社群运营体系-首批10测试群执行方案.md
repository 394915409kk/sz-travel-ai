### 1.1 逐群拉机器人（每群 2 分钟 × 10 群）

**统一动作序列**（对每个群重复）：

1. 进入客户群 → 右上角「…」→ 群管理 → 添加群机器人（部分版本在「群成员」页）→ 选择「陈桂芹的机器人」→ 确认
2. **互动解锁（关键）**：群主在群里 @机器人 发一条消息，例如 `@陈桂芹的机器人 早安打卡`——不互动则机器人后续无法主动发言
3. 群配置三件套：①「仅群主及管理员可修改群名」开启 ②人数上限 200（满员后再开500）③群公告挂群规（见第二部分）

**为什么逐群操作**：企微暂不支持批量添加机器人到多个群，10 群约 20 分钟，贝宝玉今晚一次性做完。

### 1.2 批量采集 chat_id（机器人进群后，WorkBuddy AI 执行）

```bash
wecom-cli message aibot sessions list
```

在返回列表中按群名找到 10 个新群的 chat_id，登记进配置文件：
`/Users/tiantiankuaile/WorkBuddy/2026-08-20-11-16-17/.workbuddy/customer_groups.json` 的 groups 数组。

**采集时机注意**：
- sessions list 上限 20 个会话——内部 2 群 + 新建 10 群 = 12 个，在限内，但**必须在建群当晚采集**（会话列表按最近互动排序，隔几天可能被挤出）
- 若某群没出现在列表：回该群再 @机器人 一次，立即重跑命令

**采集完成后的验收**：配置文件 groups 数组 10 行均有 chat_id → 第4路早安推送即可按群定制线路内容（塞班群推塞班内容，其他群推当日主题）。

### 1.3 常见异常处理表

| 异常现象 | 根因 | 解决方法 |
|---|---|---|
| 群管理里找不到「添加群机器人」 | ①群是普通内部群不是客户群 ②企业管理员未开放机器人入群权限 | 确认建群时选了「客户」；KK 在管理后台 work.weixin.qq.com → 应用管理 → 智能机器人 → 开启「允许加入客户群」 |
| 机器人进群但发不出消息 | 未互动解锁 | 群主 @机器人 发一条消息即解锁 |
| sessions list 找不到新群 | 24h 内无互动被排序挤出 | 群内再 @机器人 一次，立即重跑 |
| 推送返回 errcode 853006 | 企业权限拒绝 | 检查机器人权限授权是否过期/被收回，重新授权 |
| 机器人发言带「陈桂芹」署名观感不对 | 授权身份显示 | 群内话术统一以「职旅AI助手/职旅小助手」自称，首发消息说明「我是群助手，行程问题@我」 |

## 三、获客裂变闭环：渠道活码 + 四渠道引流方案

### 3.0 闭环全景

```
渠道触点（OTA/门店/公众号/抖音）
   ↓ 扫渠道活码
加企微好友（自动打渠道标签 + 自动欢迎语）
   ↓ 欢迎语引导
拉入对应线路群（欢迎语承接 + 群规）
   ↓ 30天内容日历培育
客户开口咨询 → 录入《客户跟进表》（30秒/条）
   ↓ 三路自动化盯转化（激活器/哨兵/话术库）
成交 → 进《老友福利群》复购
   ↓ 老带新礼遇
转介绍新客 → 回到闭环起点（标签「转介绍」）
```

### 3.1 渠道活码搭建（KK 在企微管理后台操作，30 分钟）

**操作路径**（电脑端）：

1. 登录 work.weixin.qq.com → 「客户联系」→「加客户」（部分版本叫「联系我」/「渠道活码」）
2. 点「新建」→ 选择方式「单人/多人」（**选多人**：使用人员添加贝宝玉+全部客服，客户随机分配不漏接）
3. 每个渠道建一个活码，命名规范：`渠道-用途`，共 4 个：
   - `OTA-订单客户`、`门店-到店客户`、`公众号-粉丝`、`抖音-粉丝`
4. **自动打标签**（关键配置）：每个活码在「客户标签」处绑定对应标签（OTA/门店/公众号/抖音）——客户扫码加好友时标签自动落，这是数据闭环的第一颗铆钉
5. 生成二维码 → 下载 → 各渠道投放

**验收标准**：用个人微信扫 4 个码，都能加上企微好友，且自动收到对应渠道标签。

```
扫码加好友 ──→ 企微自动打【渠道标签】（OTA/门店/公众号/抖音）
客户进群/开口 ──→ 顾问录《客户跟进表》：姓名+来源渠道（对应标签）+意向线路+咨询时间（30秒）
报价后 ──→ 顾问更新：跟进状态=已报价、意向等级H/W/C、下次跟进日期
成交后 ──→ 顾问更新：跟进状态=已成交 → 拉进老友群
超7天未动 ──→ 沉睡激活器自动识别（不需要人工标"已沉睡"，按时间自动算）
用话术成交 ──→ 顾问在《爆款话术库》点"✅已采纳"+采纳次数+1
```

**关键设计**：沉睡/超时判定全部按时间字段自动计算（今天日期 − 最近跟进时间/最近咨询时间），顾问只需要做「录入+更新状态」两个动作，其余全部自动。

### 4.3 用户行为追踪机制（当前能力与升级路径）

| 行为 | 当前追踪方式 | 载体 |
|---|---|---|
| 来源渠道 | 活码自动打标签 + 跟进表「来源渠道」字段双轨 | 企微原生+智能表格 |
| 意向线路/等级 | 顾问每次跟进后人工更新（H/W/C） | 跟进表 |
| 群内活跃 | 群主每周日目测登记（开口人数/活跃话题）到周复盘 | 演练群周报 |
| 咨询响应时效 | 哨兵自动盯（咨询>4h未跟进） | 跟进表+待办 |
| 话术有效性 | 采纳次数累计 | 话术库 |
| 成交转化 | 跟进状态=已成交 的记录数 | 跟进表 |

**能力边界（如实说明）**：因企业未开通会话存档，群聊内容级追踪（谁说了什么、点击了什么链接）暂不可自动采集。现阶段的追踪颗粒度=「字段级」（谁、何时、什么状态），足够支撑漏斗分析；若未来需要消息级追踪，需企业开通会话存档付费权限（届时再评估）。
