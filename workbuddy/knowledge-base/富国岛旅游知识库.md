## 二、签证政策（免签重点！）

> 数据来源：中国外交部领事司《越南签证入境》官方信息（2026-08-21 复核）

### 2.1 富国岛免签政策——中国公民免签 30 天

**富国岛是越南唯一对中国普通护照免签的区域**，最长停留 30 天。但享受免签须同时满足以下条件，**缺一不可**：

| 条件 | 说明 |
|---|---|
| **护照有效期** | 自抵达日起至少 6 个月 |
| **直达航班** | 从境外（如中国香港/内地/台湾）**直飞**富国岛国际机场（PQC），不能经越南境内城市转机 |
| **活动范围** | 全程仅在富国岛内活动，**不得前往越南其他地区** |
| **停留时长** | 不超过 30 天，须备好回程机票 |
| **签证记录** | 无被越南驱逐出境或严重违法记录 |
| **入境口岸** | 由空路或海路直达富国岛 |

### 2.2 三大常见误区（客服必读）

| 误区 | 正确答案 |
|---|---|
| ❌「经胡志明市转机到富国岛也算直飞」 | ✅ **不算**。凡经河内、胡志明市、岘港等越南境内城市转机，系统认定先进入越南本土，**必须提前办理越南签证** |
| ❌「可从富国岛坐船去胡志明市一日游」 | ✅ **不能**。一旦离开富国岛前往越南本土，即视为非法入境，须补办签证 |
| ❌「回程也必须从富国岛直飞」 | ✅ **不需要**。只要入境时为直飞富国岛，30 天内可从越南任何口岸离境（实践中仍建议原路直飞返回，避免边检风险） |

### 2.3 入境所需材料

| 材料 | 要求 |
|---|---|
| **护照** | 有效期 6 个月以上，含空白签证页 |
| **往返机票** | 已确认往返机票订单（返程在 30 天内） |
| **酒店订单** | 全程酒店预订确认单 |
| **入境章/凭证** | 抵达富国岛机场后办理免签入境手续，领取另纸凭证（盖在护照上的入境章），**务必妥善保管直至离境** |
| **现金** | 建议准备适量现金（入境可能抽查），刷卡为辅 |

> **客服提醒**：免签不等于「零手续」，抵达后仍需在富国岛国际机场办理入境手续并领取凭证。若行程计划包含河内/胡志明市等越南本土城市，请务必提前办理**越南电子签证（E-Visa，最长 90 天，在线申请，官方处理约 3 个工作日，建议提前 1–2 周提交）**或另纸签证。
