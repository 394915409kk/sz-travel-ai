## 这个分支是什么

`sz-travel-ai` 的 `main` 分支是 codex 搭建的 AI 系统代码基线（最新提交 b86e7bf，2026-06-27，PR #12 生产数据库迁移框架）。
本分支是 **WorkBuddy 的独立运营基线**，存放 WorkBuddy 侧的治理文档、记忆体系与交付物，与 codex 系统基线完全分离，互不干扰。

## 治理框架

- **6 步闭环**：使用 → 沉淀 → 学习（三审） → 固化（锁库） → 复用 → 扩展
- **4 条原则**：三审前置、机密隔离、锁库追溯、真实可验
