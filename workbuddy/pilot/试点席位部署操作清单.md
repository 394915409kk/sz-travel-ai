# 试点席位部署操作清单

> 目标：把 2 个新增席位分配给贝宝玉（OTA 运营总监）和财务岗位
> 时间：2026-08-21 | 操作人：KK（管理员）

---

## 第一步：创建员工账号

### 1.1 进入成员管理
1. 打开 WorkBuddy 桌面端
2. 点头像（左下角）→ 「企业控制台」
3. 左侧菜单 → 「成员授权」→ 「成员管理」（或「组织概览」→ Step 1「添加成员」）

### 1.2 添加贝宝玉
1. 点「添加成员」或「邀请成员」
2. 填写信息：
   - 姓名：贝宝玉
   - 岗位/角色：OTA 运营总监（携程/同程）
   - 手机号/邮箱：填写贝宝玉的常用手机号或企业邮箱
   - 部门：运营部（或按实际填写）
3. 点「确认添加」或「发送邀请」

### 1.3 添加财务岗位员工
1. 同上步骤，添加财务岗位员工
2. 填写信息：
   - 姓名：（财务员工姓名）
   - 岗位/角色：财务
   - 手机号/邮箱：财务员工的常用手机号或企业邮箱
   - 部门：财务部
3. 点「确认添加」或「发送邀请」

> **注意**：如果系统提示需要「腾讯统一身份平台」授权，按提示跳转完成授权即可。

---

## 第二步：分配许可证（旗舰版席位）

### 2.1 进入许可证分配
1. 在「组织概览」页面 → 点 Step 2「去授权」（或「成员授权」→ 「分配许可证」）
2. 看到成员列表，找到刚才添加的两位员工

### 2.2 分配席位
1. 在贝宝玉一行 → 点「分配」或「授权」→ 选择「旗舰版」→ 确认
2. 在财务员工一行 → 同上操作 → 选择「旗舰版」→ 确认
3. 确认页面显示：剩余席位 0/3（3 个席位全部分配完毕）

> **验证**：两位员工状态应从「未分配」变为「已激活」或「旗舰版」。

## 第四步：首次登录验收

### 4.1 验收清单（请两位员工完成）

| 验收项 | 贝宝玉 | 财务 |
|---|---|---|
| 能正常登录 WorkBuddy | ☐ | ☐ |
| 能新建任务并输入问题 | ☐ | ☐ |
| 能收到 AI 回复/文件 | ☐ | ☐ |
| 能下载/保存结果文件 | ☐ | ☐ |
| 看过岗位指南 | ☐ | ☐ |
| 完成第一个测试任务 | ☐ | ☐ |

### 4.2 常见问题处理

| 问题 | 解法 |
|---|---|
| 登录提示"账号不存在" | 检查账号是否输错，或重新在企业控制台确认成员已添加 |
| 登录后看不到旗舰版功能 | 检查许可证是否已分配（组织概览 → 去授权） |
| 收不到邀请短信/邮件 | 检查手机号/邮箱是否填对，或直接在后台重置密码 |
| 不知道问什么 | 直接复制岗位指南里的「提问模板」粘贴进去 |

## 第五步：一周后复盘

### 5.1 收集反馈（第 7 天）
询问两位试点员工：
1. 这周用 WorkBuddy 做了几件实事？
2. 哪件事最省时间？
3. 哪里不顺/不会用？
4. 还需要什么技能/功能？

### 5.2 决策扩量
如果两位试点员工：
- **周活 ≥ 90%**（每周至少用 3 天以上）
- **有 1 个以上真实业务产出被采纳**
- **反馈积极**

→ **结论：降本增效验证通过，建议继续增购席位**

如果：
- 使用率低于 50% 或反馈负面
- → 先解决卡点（培训/模板/场景不匹配），再扩量
