- **求职表疑似造假**：打码≠造假证据。以第 8／26／39(5) 条解除须具备：岗位有明确学历／经历要求、员工签字承诺真实、虚假客观可证、足以影响录用决定、制度经民主程序＋公示、通知工会；工龄长短通常不构成。且林若慈是 P0 合同逾期人员，硬解除会同时引爆二倍工资＋2N＋年假时效重置＋报复性解除叙事。**结论：不解除、不调查造假、不写「碰瓷／造假」**。
