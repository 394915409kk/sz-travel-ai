```bash
# .doc（旧二进制）→ txt（macOS 原生）
textutil -convert txt -encoding UTF-8 -output "OUT.txt" "IN.doc"
# .docx / .pptx → txt：用托管 venv

# 表格行需对合并单元格去重：相邻相同 cell 只保留一次
# pptx 遍历 slide.shapes，取 text_frame.text + shape.table.rows
```
