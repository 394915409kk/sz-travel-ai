## 一、项目定位

面向深圳市职工国际旅行社的旅游商品销售智能体。把真实商品素材、图文行程、逐项报价、点击替换、交易前核价、生成订单串成一条闭环。
客户交互流程固定四步：AI 帮我安排 → 我的旅行方案 → 调整方案 → 核价并预订。
交付渠道：H5 链接加飞书消息直贴版。

## 三、时效与文案红线（硬规则）

01｜航班时刻与班期一律以当季航司正式时刻表及民航局批复为准，写「待航司公布」「以实际出票为准」，禁止引用历史航季（太阳富国航班团期表 5-9 月版只存档不引用）
02｜入境政策统一写「以官方最新公告为准，待核实」，禁止写「白本免签说走就走」
03｜富国岛自费项目表价格适用至 2026/06/30，已过期，只取项目名做加购目录，价格一律写「待供应商重新核价」
04｜推荐打卡不等于门票已含，不得写成「门票已含」
05｜成本 CSV 与定价模型里的采购价属内部成本，只进核验页，不进客户详情页
06｜对客文案一律飞书消息直贴版：禁 Markdown 表格与 ASCII 竖线、加粗符、标题符；层级用「一、」「（一）」，并列节点用全角竖线分段
07｜问道结果只作资讯补充并标注来源与返回时间，不冒充实时库存
08｜用词以 2026-11-15 KK 裁定为准：统一「阳东夜市」「接吻桥」，禁用「杨东夜市」「亲吻桥」
09｜标准产品不含门票；「一票畅玩」是商家优惠打包票，不得写成已含或写进报价
10｜高星级酒店未回源房价不得进标准套餐价；问道实时房价查询失败时改走供应商回源

## 四、技术选型与代码约定

01｜浏览器与 Node 共用同一份 engine.js（UMD），测试直接 require 产品实际加载的源码，不测替身
02｜products.js 为产品线配置层，UMD，浏览器经 index.html 在 engine.js 之前加载，Node 由 engine.js require
03｜金额用元（浏览器）与 int64 分（Go 服务端）两套，Go 侧在 server/ 下
04｜商品四要素图片／文本／报价／选项共用 sync.revision 指纹，变化即标 out_of_sync
05｜任何方案改动后 quote.verified 置 false，必须重新核价
06｜素材未审核、零库存、售价待回源（price_pending）均列为核验拦截项
07｜核验通过后仍需人工签字；境外产品还需 KK 勾选入境政策复核确认
08｜订单号格式 ZL + YYYYMMDD + 四位序列，首版无支付字段
09｜验证命令：node --test engine.test.js products.test.js；Go 侧 make all；H5 冒烟用 smoke.html 配 Chrome headless
