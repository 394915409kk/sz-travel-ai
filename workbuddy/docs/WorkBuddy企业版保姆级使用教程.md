## 1. 产品定位与界面三区

WorkBuddy 是腾讯出品的企业级 AI 办公工作台。和传统 AI 聊天最大的区别：**它不只给建议，而是直接动手干活并交付可验收的成果**（文档、表格、PPT、网页、代码、分析报告）。

界面三区：

| 区域 | 位置 | 功能 |
|---|---|---|
| 侧边栏 | 左侧 | 任务列表（按空间/文件夹分组）、搜索、任务管理；底部是用户头像与设置入口 |
| 对话区 | 中间 | 核心交互区：任务标题、消息列表、输入框、模式切换 |
| 结果区 | 右侧 | 产物预览、全部文件、变更记录、网页实时预览 |

**关键认知**：一个"任务"= 一个独立上下文。同类事情在同一个任务里追问，不要天天开新任务，上下文会断。

## 2. 三种工作模式

在输入框附近可切换：

| 模式 | 行为 | 什么时候用 |
|---|---|---|
| **Craft（你说我做）** | 直接执行：读写文件、跑命令、生成内容 | 90% 的日常任务，默认用它 |
| **Plan（先想后做）** | 先出方案和执行计划，你确认后才动手 | 大改造、批量操作、涉及删除/对外发送等高风险动作 |
| **Ask（只聊不动）** | 只回答、只读文件，不改任何东西 | 咨询、方案评审、代码审查、学习提问 |

**KK 的使用建议**：日常用 Craft；涉及"删除文件、群发消息、改自动化"这类不可逆操作时切 Plan；让 AI 帮你审方案时切 Ask。

## 3. 任务管理全操作

### 3.1 任务卡片操作（侧边栏）

鼠标悬停在某条任务上 → 点出现的「⋯」更多菜单：

- **置顶**：常用任务钉在列表顶端（建议置顶：投资四时段、职旅日报）
- **重命名**：给任务起可识别的名字
- **打开文件夹**：跳到该任务的本地目录
- **保存到工作空间**：持久保存，可多 Agent 协作、可用 IDE 打开
- **分享任务**：生成公开链接发给任何人
- **删除**：从列表移除该任务
- **归档**：归档后在「系统设置 → 数据管理」里可查回

### 3.2 空间（文件夹）操作

悬停空间名（如"自动化任务-2026-07-…"）→「⋯」：

- **新建任务**：在同一空间开新任务
- **打开文件夹**
- **从列表中移除**：整个空间从侧边栏消失（本地文件不删）

### 3.3 ⭐ 空推送会话删不掉怎么办（你遇到的问题）

你截图里那 25 个"每日 AI 新闻推送"空窗口，是旧自动化每天跑出来的**运行记录会话**。正确处理顺序：

1. **先删自动化任务本身**（✅ 我已在后台帮你删除旧任务 ID automation-1784906668237，不会再产生新空窗口）；
2. **再逐条删除历史会话**：悬停会话 →「⋯」→「删除」。如果删除按钮点了没反应（已知偶发 bug），改用以下任一方案：
   - 方案 A：对该会话点「**归档**」——效果等同删除，列表立即干净；
   - 方案 B：对整个空间「自动化任务-2026-07-…」点「**从列表中移除**」——25 条一次清掉，最省事；
   - 方案 C：「系统设置 → 数据管理」里批量清理已归档/历史任务。
3. **以后预防**：新自动化 prompt 里必须写"直接输出完整内容"（见第 7 节），就不会再产生空窗口。

## 4. Skills 技能体系

技能 = 封装好的专业能力包（你账号里已装 200+ 个）。

**用法**：正常提需求即可，系统会自动匹配技能。也可以显式点名，如"用 ppt-generator 做一份塞班岛招商 PPT"。

**你的高频技能地图**：

| 场景 | 技能 |
|---|---|
| 公文写作 | 深知公文写作、wow-gongwen-writing、govwriter-pro |
| 投标文件 | biaoshu-writer、投标文件编制专家 |
| PPT | ppt-generator、tencent-pptx、html-ppt |
| Excel/数据 | excel-data-wizard、minimax-xlsx、数据分析大师 |
| 公众号/新媒体 | wechat-write、wechat-cover、gzh-explosive-content-detector |
| 抖音短视频 | douyin-pro 全家桶（大脑/脚本/混剪/发布） |
| 金融投资 | wb-finance-skill（总入口，优先级最高） |
| 热点追踪 | hotspot-radar、douyin-hot-trend、china-hotdata |
| 合同审查 | contract-review、law-skills |

**安装新技能的铁律（你的治理原则）**：任何推荐必须先经你审核，禁止自动安装。每日 21:00「自动学习」任务会给你推送候选，你点头才装。

## 5. Experts 专家体系

左侧边栏「**专家**」入口 → 专家中心 → 按分类浏览 → 点选即开聊。

- 专家 = 带专业角色、方法论和工作流的会话人格（如"超级金牌股神"之于你的投资组合）
- 专家与技能的区别：**技能是工具，专家是用工具的人**
- 同一时刻只启用一个专家/专家团；需要多角色协作时可组"专家团"
- 你也可以把自己的方法论沉淀成私有专家（expert-manager 技能）

## 6. Connectors 连接器

连接器 = 打通外部应用（飞书、GitHub、腾讯文档、企查查、Wind 等 100+ 个）。

**连接路径**：左侧边栏底部头像 / 连接器管理页 → 找到目标应用 → 点「连接」→ 按引导授权。

### ⭐ 6.1 飞书重连步骤（当前必须做）

你账号的**飞书连接器现在是断开状态**——这是"日报没有真实推送到飞书群"的根因之一。重连：

1. 打开 WorkBuddy → 左侧边栏底部点你的**头像**（或右上角设置入口）→ 找到「**连接器**」管理页；
2. 在列表里找到「**飞书**」（当前显示 disconnected）；
3. 点「**连接 / 重新授权**」→ 跳转飞书授权页 → 用管理员账号登录并同意授权；
4. 回到 WorkBuddy 确认状态变为「已连接」；
5. 发一条测试："给飞书群发一条测试消息"，验证打通。

### 6.2 自定义 MCP

进阶玩法：任何支持 MCP 协议的服务都能接入（配置写在 `~/.workbuddy/mcp.json`）。配好后需到连接器管理页点「信任」才生效。

## 7. 自动化任务：正确搭建 SOP（重点）

### 7.1 空推送失败根因复盘

你的旧"每日 AI 新闻推送"为什么每天产空窗口：

| 病灶 | 后果 |
|---|---|
| prompt 只有一句"关注 AI 动态"，没指定用搜索工具 | 模型空手跑，无内容产出 |
| 没要求"直接输出全文" | 结果可能没落进会话窗口 |
| 跑在一个空工作区 `automation-2026-07-24-23-24-28` | 无上下文、无记忆、无工具环境 |
| 无失败兜底（没新闻时该干嘛） | 极端情况输出空白 |

### 7.2 ✅ 正确搭建七步 SOP

**第 1 步：想清楚"交付物是什么"**
自动化不是"跑一下"，而是"每天定时交付一份东西"。先定义：交付物是群里一条简报？一份 Excel？一个网页？

**第 2 步：选对工作区（cwds）**
自动化必须挂在**有上下文的工作区**上（比如本工作区），不要挂空目录。工作区决定它能读什么文件、用什么记忆。

**第 3 步：写自包含的 prompt（最关键）**
自动化运行时没有你在场，prompt 必须独立成立。合格 prompt 五要素：

```
① 角色：你是谁（如"你是 KK 的 AI 资讯情报助理"）
② 工具：明确说用什么（"使用 WebSearch 搜索…"、"加载 wb-finance-skill"）
③ 交付：明确产出格式与数量（"筛选 3-5 条，每条含标题/概述/原因"）
④ 落点：内容放哪（"必须在最终回复中直接输出全文" / "推送到飞书群"）
⑤ 兜底：异常情况怎么办（"如无重大新闻，输出本周趋势总结，禁止空白"）
```

**第 4 步：定调度规则**
- 每天：`FREQ=DAILY;BYHOUR=8;BYMINUTE=0`
- 工作日：`FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=9`
- 一次性：设定具体日期时间
- 可选有效期：validFrom / validUntil（如展会提醒，过期自动停）

**第 5 步：依赖的连接器和技能先就位**
要推飞书 → 先确认飞书连接器已连接（见 6.1）；要用金融数据 → 确认 westock-data CLI 可用。**连接器断开 = 任务空跑**。

**第 6 步：手动试跑一次验收**
建好后别等明天——先手动触发或建一个 5 分钟后的一次性任务试跑，检查：内容是否完整？推送是否到达？格式是否可读？验收通过再转正式周期任务。

**第 7 步：纳入治理台账**
在 MEMORY.md 记录：任务名、调度、工作区、依赖连接器、验收日期。符合你"锁库追溯"原则。

### 7.3 失败排查清单（以后照这个查）

- [ ] 会话窗口空白 → prompt 没要求"直接输出全文"
- [ ] 跑了但没推送 → 对应连接器断开（重连）
- [ ] 完全没跑 → 电脑休眠/WorkBuddy 未运行（桌面端定时任务需要 App 在线）
- [ ] 内容质量差 → prompt 缺角色/工具/格式定义
- [ ] 重复推送 → 存在多个同名自动化（list 检查，删旧留新）
- [ ] 时区不对 → 调度按本地时间，确认系统时区

## 8. 记忆系统

WorkBuddy 有三层记忆，你越用越顺手靠的就是它：

| 层 | 位置 | 用途 |
|---|---|---|
| 云端画像 | 自动 | 你的长期偏好，每次会话自动注入 |
| 用户级记忆 | `~/.workbuddy/MEMORY.md` | 跨项目的硬性规则（如"所有推荐先审核"） |
| 工作区记忆 | 工作区 `.workbuddy/memory/` | 本项目的工作日志和长期笔记 |

**进阶**：`~/.workbuddy/SOUL.md`（人格）、`USER.md`（你的档案）、`IDENTITY.md` 都可以让我更新——比如把"职旅日报必须 6 条文旅爆款"写进记忆，我以后自动遵守。

## 9. 资料库 / 发布应用 / 分享

- **资料库**：在线文档、数据表、看板、网盘，团队共享知识库（说"放进资料库"即可）
- **发布应用**：做好的网页/小工具可一键发布成在线应用，生成分享链接；管理入口在「**设置 → 数据管理 → 我发布的应用**」
- **分享任务**：任务卡片 → 分享 → 生成公开链接，投资人/同事直接看成果

## 10. 额度与企业管理

- 企业旗舰版 1 席位 4000 额度：复杂任务（深度研究、多技能串联）消耗多，简单问答消耗少
- 自动化任务每次运行也消耗额度——**空跑任务是纯浪费**，这也是要尽快清掉坏任务的原因
- 查看用量：头像 → 账号/额度页面
- 扩席位：后续「职旅AI成长计划」12+ 岗位扩量时，按岗位加席位

## 11. KK 专属：6 步闭环 × 4 条治理原则落地

| 环节 | WorkBuddy 里的落点 |
|---|---|
| ① 使用 | 日常任务全走对话，别手工干 |
| ② 沉淀 | 跑通的工作流 → 存成 Skill；偏好规则 → 写进 MEMORY.md |
| ③ 学习（三审） | 每日 21:00「自动学习」任务推送技能/专家候选 |
| ④ 固化（锁库） | 审核通过的技能/专家才安装；重要配置记台账 |
| ⑤ 复用 | 下次直接点名技能/专家，一句话复现 |
| ⑥ 扩展 | 验证成熟的能力复制到 12+ 岗位（职旅AI成长计划） |

四条原则对应动作：
- **三审前置** → 任何安装/外发前问你
- **机密隔离** → 敏感项目用独立工作区，不跨区引用
- **锁库追溯** → 自动化/技能台账进 MEMORY.md
- **真实可验** → 交付物必须可打开、可复核、可复跑
